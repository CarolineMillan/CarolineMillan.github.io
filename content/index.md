# About Me

Software engineer with a Mathematics MSc. I enjoy using mathematical ideas in my projects, and understanding how things work by building them.

Recent projects include a [VM Translator](https://github.com/CarolineMillan/HackVMTranslator) and an [assembler](https://github.com/CarolineMillan/HackAssembler_hs) (from the course [From NAND to Tetris](https://www.nand2tetris.org/)), a grep-style [regex engine](https://github.com/CarolineMillan/grape), and revisiting my [ray tracer with photon mapping](https://github.com/CarolineMillan/raytracer_cpp). I work mostly in C++, with projects in Rust, Haskell, Python and Go.

My professional experience is writing Magik for GE Smallworld, which is GIS software dealing with large-scale geospatial databases.

For more information, see my [CV](/cv) or [projects](/projects).
